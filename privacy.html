Studio Uploader – Privacy Policy

Last updated: 22 November 2026

Studio Uploader is a private tool run by 61c on a single computer. Its only job is to upload our own videos to our own YouTube channel. It is not offered to the public and has no other users.

What it accesses

With the channel owner's permission (Google sign-in), it uses the YouTube Data API to upload videos with their title, description and tags, and to read the channel's name so it can confirm it is uploading to the right channel. It does not read, collect or store anyone else's data.

What is stored

The sign-in token is stored only on our own computer, so the tool can keep uploading without asking for the password again. Nothing is sold, shared or sent to anyone except YouTube/Google as part of the upload.

Google and YouTube

Studio Uploader uses YouTube API Services. By using it, you also agree to the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy. Access can be removed at any time at myaccount.google.com/permissions.
